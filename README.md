# BioWorth

BioWorth is a web-based economic assessment tool for green biorefinery processes.

The tool is designed to support preliminary economic assessment by allowing users to enter process and cost parameters and calculate key economic indicators, including capital expenditure and operating expenditure.

## Access the tool

The BioWorth app is available here:

https://bioworth-protected.onrender.com

Access is restricted and requires a valid access code.

## Intended users

BioWorth is designed for researchers, students, project partners, and non-expert users who need a simple interface for preliminary economic screening of biorefinery systems.

## Main features

- CAPEX assessment
- OPEX assessment
- Equipment-based cost input
- Labor cost estimation
- User-friendly interface
- Protected access for controlled sharing

## Project status

BioWorth is currently a research prototype under development.

The tool is intended for research, education, and preliminary screening. Results should not be used as the only basis for commercial investment decisions.
